# 家书 Android 0.3.6

实机对照已确认：32 位十六进制 ID、九资源图片正文、版本 1 的测试 C 在云笔记 1.13.6 可见且内容正常；相同正文的 33 位测试 D 不可见。0.3.3 新消息采用已验证组合，保留旧消息识别。0.3.2 只有补登记、没有编号修复，继续保留为内部诊断版本，不推荐安装。

独立 Flutter 客户端，使用学生自己的学校账号登录，供家长选择“爸爸”或“妈妈”作为消息署名。当前可发送云笔记正文，**还不是已完成的双通路聊天产品**。

## 家长使用

1. 安装 APK，输入学校代码、学生账号、密码，选择爸爸或妈妈。
2. 学校网关只提供 HTTP 时，需要在登录页明确勾选同意。程序不会忽略无效 HTTPS 证书。HTTP 会暴露传输中的密码、令牌和消息；兼容编码不是安全加密。
3. 登录并同步后，云笔记根目录会出现专用「家书」目录。点击“开启话题”创建目录；进入话题直接发送笔记消息，点击“开分支”创建子话题。根目录也保留日常消息和旧笔记。
4. 右上角设置 → 开启后台接收，允许 Android 通知。系统通知渠道可以由手机设置关闭；省电限制、强制停止、断网、学校限制都会影响及时性。当前不自动开机启动。
5. “服务器已保存”只表示已回读确认，不表示学生平板已同步、已送达或已读。
6. 点击消息旁“⋯”可删除消息。删除原消息会同时移除关联的更新提醒，并停止对这条笔记的内容提醒；单独删除更新提醒保留原消息，后续新的修改仍会提醒。待发消息删除后取消发送／重试，结果未确认的消息可能已经在云端。同步占用中会提示稍后删除。
7. 目录卡片右侧菜单支持“删除目录”，进入目录后右上角菜单支持“删除当前目录”。确认后，本机一并隐藏目录、全部子目录、消息和关联更新，清除未读，取消其中的待发消息；其他话题不受影响。从目录内部删除后自动回到保留的上级或日常消息，相关本机草稿同时清除。后续在被隐藏目录中新增的内容也不显示、不提醒。

删除仅从这台手机的列表中隐藏，数据库保留必要历史和删除标记来防止同步恢复；不等于彻底擦除文件或云端撤回。退出再登录保留删除标记；卸载或清除应用数据后，本机标记消失，重新同步可能再次出现。其他家长手机不受影响。支持普通消息、笔记更新提醒及话题目录，目前没有恢复入口。

## 自动登录与升级

0.2.1 起，成功登录后将密码保存在 Android 安全存储（加密 SharedPreferences，由 Android Keystore 保护）。密码不进入聊天数据库、日志或 APK；系统备份已关闭。退出登录会删除密码和令牌，保留本地聊天记录。

从 0.2.0 及更早版本升级需要退出并手动登录一次，因为这些版本没有保存密码；0.2.1 已保存的登录会保留。之后前台、后台同步会共用安全存储中的最新令牌，临近到期或收到 401 时自动调用正常登录接口。当前测试学校签发的令牌约 2 小时有效；App 读取令牌的实际 `exp`，不硬编码 2 小时。

断网、服务器暂时故障时按 1–5 分钟退避重试。密码错误、需要短信验证／改密或重新登录后仍被拒绝时，会停止自动尝试，并提示打开家书重新登录；官方验证不会被绕过。自动登录只复用用户已同意的 HTTP 传输选项，不会自动接受新的明文传输条件。

退出与令牌更新通过本地互斥和登录代次检查协调，避免进行中的自动登录把已退出的账号恢复。后台自动登录仍依赖 Android 允许后台服务运行；不会改变强制停止、断网时无法收信的限制。

## 孩子使用原版云笔记

1. 在中育云笔记保存并同步，打开根目录中的「家书」。
2. 文件夹就是话题。新建笔记和话题的名称只显示署名和内容，例如“爸爸：放学后聊聊”。进入话题即可打开笔记。旧版标题中的协议编号仍可识别。
3. **在当前话题目录新建笔记写回复**，保存并同步。每条笔记都是独立发言，同目录内彼此平级；不需要每次回复都创建文件夹。
4. 想开启分支时，新建子文件夹，用名称写话题／消息，再进入其中继续新建笔记聊天。
5. 也可以直接在家长笔记中续写，保存并同步。家书检测到内容变化后，会在所在话题新增一条“笔记有更新”未读消息，并触发来信提醒；原消息保留。多页内容属于同一条笔记。

家书按话题保留输入草稿，未读列表可以跳到消息所在话题。“本话题已读”不会清除其他分支里的未读消息。目录移动、标题改名不会生成续写消息；资源内容变化会更新原笔记并新增一条未读更新消息。同一内容重复同步不重复提醒，后续再次改变（包括恢复到以前内容）会产生下一条更新。删除或移出家书的记录保留本地历史，禁止向失效话题继续发送。

家长和孩子共用账号，接口无法可靠区分修改者，因此统一提示“笔记有更新”。更新消息显示的是原笔记的最新页面，不是历史截图或新增文字差异；旧消息中的图片也可能随服务器内容更新。多次续写发生在两次查询之间时只能发现最终状态，不能还原每次编辑。孩子须同步更新后的预览图才能在家书看到新页面。

本地数据库升级到版本 3，保留聊天记录、待发送消息及已保存的登录。首次读取缺少资源摘要的旧笔记时只建立基线，不把历史内容当成续写提醒；升级前至首次基线之间的修改无法单独识别。原先根目录笔记仍是日常消息，目录短笺显示为话题，不自动搬动云端资料。parentId 表示话题归属，不代表精确引用某一条笔记。

新增或元数据改变的笔记立即查询资源。对元数据未改变的旧笔记，满 1 分钟后按最久未检查优先轮询资源摘要，每轮最多额外检查 20 条；大量历史笔记时可能更久。资源摘要变化会刷新预览缓存，避免同 URL 内容更新后仍显示旧图。客户端最多遍历 64 层目录作为异常数据保护，这不是平台深度上限的结论。

2026-11-21 实机联调：云笔记 1.13.6 原先看不到家书／AI 助手生成的笔记；复制孩子原生四资源样本的测试 A（32 位十六进制 ID）在版本从 0 升为 1 后已可见，且能打开显示“测试123”。测试 B（33 位 ID）在版本 0 和升到 1 后均不可见。C（32 位 ID）和 D（33 位 ID）使用同一份家书九资源正文，均版本 1；用户确认 C 可见且内容正常，D 不可见。已证实本机使用的 32 位格式可用，但尚不能区分限制来自长度、字符集或其他编号规则。图片笔记不是可选中复制的文字文档。

0.3.3 同步时只补登记家书私有目录中协议 UUID 与 32 位文件 ID 一致的版本 0 笔记；确认预览资源后，重新读取标题、父目录、资源地址及共享状态，再以原五字段补登记一次。既有 version≥1 的条目不重复补登记；响应丢失后先回读，不重复上传资源；未确认版本提升时保留待核对状态。孩子自己创建的普通笔记不补登记。补登记前后的回读能发现元数据冲突，但后端没有已确认的条件更新接口，无法保证多个设备同时改名／移动时绝对无竞争；联调时应避免同时修改同一条目的元数据。

升级保留密码、聊天记录和旧 33 位协议识别。尚未登记到服务器的旧待发消息改用 32 位编号继续发送；已登记的旧笔记继续读取，不自动重建、删除或补登记。需要让孩子重新收到旧消息时，请在新版中重新发送对应文字。若同一个协议标题对应两个不同远端对象，则分别保存内容，避免相互覆盖。新笔记的资源地址与 fileUrl 沿用测试 C 的 HTTP 登记形式；实际上传及家书图片下载仍使用校验域名的 HTTPS。

原生写入参考用户提供的 `E:\1.project\zhongyu\zhongyu-ai\zhongyu-ai\app\zy_upload.py`。复用了该项目 `ZhongYuToolBox_Rev/public/example` 的 7 个二进制模板，保留其固定图片文件名引用；页面预览和正文图片均由家书生成。二进制模板通过 `.gitattributes` 禁止 Git 换行转换。无需 AI 服务、模型密钥或额外 VPS。

## 双通路尚缺什么

在线专栏的真实账号测试可以获取目录，但页面列表为空。不能据此推断学生版所有功能都不可用，也不能把任意教师/班级页面当作私信入口。

`ColumnsAdapter`保留了从原版代码确认的评论读写接口，但生产 UI 没有开启它。还需要一张正常可用的专用页面、明确的接收范围，以及一条学生正常回复样本，才能实现返回结构映射、双通路消息 ID 去重和真正的自动切换。当前**没有**自动专栏备用发送。

云笔记和专栏共用学校账号及后台，不能解决学校对账号整体停用或网络整体阻断的问题。

## 代码结构

- `lib/protocol.dart`：原版日期编码、响应判断和短笺协议。
- `lib/api.dart`：正常账号登录、云笔记、专栏适配边界。
- `lib/auth.dart`：到期检查、401 恢复、最新令牌复用、登录失败退避和需要人工处理的状态。
- `lib/native_note.dart`：页面渲染、模板资源、临时上传凭据参数、OSS 签名上传；只使用已验证官方存储域名，上传不携带学校 Bearer。
- `lib/data.dart`：安全会话和按账号隔离的 SQLite 存储。
- `lib/sync.dart`：回读确认、重试和收件处理。
- `lib/topics.dart`：私有话题树、父子关系、分支路径和未读汇总。
- `lib/alerts.dart`：通知和 Android 前台接收服务。
- `lib/main.dart`：登录、聊天、通路状态和学生回复说明。

本地聊天记录位于 Android 应用私有数据库中，退出登录后保留，卸载清除；系统备份关闭。请求错误不输出密码、令牌或服务器原始响应。原有学习资料不会改写。
